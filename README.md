- **Total cycle duration:** 7 minutes  
- **Phase length:** 105 seconds  
- **Phases:** 4 predictable lunar stages  

| Lunar Phase | Available Resources |
|------------|--------------------|
| 🌑 New Moon | Rare materials (e.g. **Carbon**) |
| 🌓 First Quarter | Common materials (**Oxygen**, **Hydrogen**) |
| 🌕 Full Moon | **All resources available** |
| 🌗 Last Quarter | Transitional mix (e.g. **Oxygen**, **Silicon**) |

Master the timing, and Luna4 becomes a strategic advantage:

- AI agents that adapt naturally to the cycle  

Simple. Predictable. Satisfying.
